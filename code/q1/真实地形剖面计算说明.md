# O01 与 15 个服务区 DEM 分布及首条真实地形剖面

## 1. 任务说明

本任务完成两项工作：

1. 将调度中心 O01 和 15 个服务区 S001–S015 标注在镇龙乡及周边 DEM 上。
2. 沿 O01→S001 直线航段提取第一条真实地形剖面。

## 2. 数据来源

| 数据 | 文件 | 说明 |
| --- | --- | --- |
| 数字高程模型 | `D题/数据/镇龙乡地理空间数据/镇龙乡及周边地理数据/数字高程模型数据（DEM）/镇龙乡及周边30米DEM.mat` | Copernicus DEM GLO-30，坐标系 EPSG:4326 |
| 调度中心与服务区 | `D题/数据/无人机应急物资运输基础数据/调度中心与服务区.xlsx` | O01 及 S001–S015 的经纬度和标称高程 |

原始数据仅读，脚本不会修改原始 DEM 或 Excel 工作簿。

## 3. 计算方法

### 3.1 DEM 点位图

- 读取 DEM 网格、经度轴、纬度轴和 NoData 值。
- 用地形设色与阴影渲染表现起伏。
- O01 使用红色星形标记，S001–S015 使用青色圆点标记。
- 在底图上用黄色虚线标出 O01→S001 剖面位置。

### 3.2 O01→S001 剖面

O01 和 S001 坐标为：

| 点位 | 经度（°E） | 纬度（°N） | 工作簿标称高程（m） | DEM 插值高程（m） |
| --- | ---: | ---: | ---: | ---: |
| O01 | 109.2308517 | 23.0085095 | 127.7 | 128.4 |
| S001 | 109.2432319 | 23.0335927 | 154.0 | 153.4 |

剖面提取流程如下：

1. 计算 O01 与 S001 之间的球面水平距离。
2. 沿两点的地面直线投影等距离布设采样点。
3. 以 30 m 为最大目标间距，实际产生 104 个采样点，相邻点水平间距约 29.74 m。
4. 对每个采样点进行 DEM 双线性插值，得到连续地形高程。
5. 根据相邻采样点的水平位移和高程差，计算地表折线长、累计爬升和累计下降。

## 4. 主要结果

| 指标 | 结果 |
| --- | ---: |
| O01→S001 水平距离 | 3.063 km |
| 地表剖面折线长 | 3.183 km |
| 采样点数 | 104 |
| 实际采样间距 | 29.74 m |
| O01 DEM 高程 | 128.4 m |
| S001 DEM 高程 | 153.4 m |
| 净高程变化 | +25.0 m |
| 剖面最低高程 | 128.4 m |
| 剖面最高高程 | 222.7 m |
| 最高点距 O01 的水平距离 | 1.933 km |
| 累计爬升 | 353.0 m |
| 累计下降 | 328.0 m |

O01 到 S001 虽然净高程变化只有约 25 m，但航段中间穿过多个局部山脊和沟谷，剖面最高点达 222.7 m。因此，无人机航迹设计不能只比较起终点高程，还需考虑航段中间的地形净空要求。

```powershell
python -X utf8 "code/q1/真实地形刨面图"
```

脚本会自动重新生成两张图、剖面采样表和结果摘要。

## 7. 使用注意

- “30 m DEM”表示数据的名义地面分辨率，不代表高程误差为 30 m。
- 剖面为 O01 到 S001 直线地面投影上的 DEM 高程，不是已优化的无人机三维航迹。
- “地表剖面折线长”是根据采样点计算的地形折线长，不应直接作为飞行距离。
- 工作簿标称高程与 DEM 双线性插值高程属于不同口径；本剖面统一使用 DEM 插值值。
